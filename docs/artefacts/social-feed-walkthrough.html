How it works

Seven small steps, in order.

The whole thing is opt-in and lives behind one toggle. Here's the path from "off" to a live feed — nothing turns on until you ask it to.

01

Turn it on

Social is off out of the box. Flip it on in Settings → Social when you feel like it; leave it off forever and Perch is exactly as it was.

Settings · off by default
Social feed
Show friends' statuses under the overlay
02

Sign in with GitHub

One tap opens your browser, GitHub confirms it's you, and you're back. No new password to invent, and your email never touches Perch's own data — it stays with the login provider.

OAuth · no password, no email stored
⌘ Continue with GitHub
Opens your browser · returns automatically
03

Claim a handle

Pick a name your friends will recognise. That's the only identity you need — no real name, no profile to fill in. A handle and an optional mood, and you exist.

@handle · that's the whole profile

Add friends by handle

Search someone's exact handle and send a request. They have to accept before either of you sees the other's posts — it's mutual, always. You can't browse or stumble onto strangers.

05

Post a status

Type up to 280 characters, pick a mood, hit post. That's it — nothing is ever posted for you. Perch never lifts a line from your transcripts, file paths, or project names; the box is always yours to fill.

Watch the feed

Where the line is

You decide what leaves your machine.

Shared with friends

  • →
    The handle you chose, and a mood emoji if you set one.
  • →
    Status posts you type and send yourself — up to 280 characters.
  • →
    Only with people whose friend request you accepted.

Never leaves Perch

  • ×
    Anything from ~/.claude — transcripts, prompts, file paths, project names.
  • ×
    Your real name or email — the GitHub login keeps those.
  • ×
    A browsable directory — no one can enumerate users or find you by accident.
A concept walkthrough for a proposed, opt-in Perch feature — not a shipping product. Built on a managed backend (Supabase) with friends-only access enforced in the database, GitHub sign-in, and a transport that degrades to plain HTTPS polling behind restrictive firewalls.
