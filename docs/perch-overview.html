Windows & macOS tray app

Perch

Keep an eye on every Claude Code session from one floating panel — without alt-tabbing through a dozen terminals.

Windows + macOS System tray / menu bar .NET 10 · Avalonia Reads ~/.claude

Perch watches your active Claude Code sessions by reading Claude's own session files, and updates in near real time. One always-on-top panel shows what each session is doing at a glance.

When a session finishes, gets stuck on a permission prompt, or needs you — a dot changes colour, the panel flashes open, and a notification fires. Click a row to jump straight to that session's terminal.

Four states, colour-coded

Every session sits in one of four states — an escalation ladder from working quietly to needing you now. The header count and the flash tell you which without opening the list.

Running Actively executing, with the latest tool call and a live runtime timer ticking beneath it.
Idle Open, but not doing anything right now — nothing to act on.
Awaiting Input Stopped on a permission prompt or a question, waiting for your answer.
Needs Attention Finished recently and waiting to be acknowledged — the panel flashes and a notification fires.

What it does

One panel, plus the readouts and pings that keep you out of the terminals until something actually wants you.

Overlay panel

Per-session rows with a status dot, the current tool call and an elapsed timer. Sub-agents (Task runs) nest under their parent. Click a row to focus that terminal; drag to reposition. Shrink it to a slim edge-docked strip that expands on hover.

Usage & rate limits

Session (5-hour) and Weekly (7-day) bars, colour-coded green to red with reset counters and an expected-rate marker. Pulls the same account usage as Claude's /usage — and never calls out when the feature's off.

Notifications

Desktop toasts and system chimes when a session finishes or starts waiting — click one to jump to it. Optional push to your phone via ntfy, with an away-override that fires when your workstation is locked.

Stats & history

A dashboard of sessions, active time, prompts, tool calls, tokens and estimated cost — scoped Today / 7d / 30d / All time, broken down by project, tool and model. Read any transcript in a clean Readable view.

Permission badges

Each session shows its permission mode inline — Plan, Accept Edits, Auto or Bypass — so you can tell a locked-down session from one running loose at a glance.

Zero-setup hooks

No plugin to install: Perch points ~/.claude/settings.json at its own fast perch-hook binary, keeps it current across updates, and removes it cleanly on uninstall. That unlocks the badges and optional auto-start.

How it works

Perch reads Claude Code's own files under ~/.claude/ — live session state from sessions/{id}.json and its sidecars, and append-only transcripts from projects/ — opened shared-read and parsed defensively, so a half-written file never crashes it. Heavy work runs off the UI thread; the panel never freezes. No account, no telemetry, no network calls beyond the optional usage lookup and phone push.
