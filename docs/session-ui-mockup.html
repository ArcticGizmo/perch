Palette

Warm charcoal ground with Perch's own brand red‑orange as the one bold accent — deliberately distinct from the cool‑blue chrome elsewhere in the app. Semantic hues (green/amber/red/violet) carry state and never stand in for the accent.

Typography

Bricolage Grotesque carries the wordmark, headings and labels — characterful and a touch playful. Hanken Grotesk reads the prose. JetBrains Mono handles code, tool args, ids and paths.

Structure

Turns are composed units, not a flat log: user in a warm bubble, Claude as open prose under the bird mark, with thinking, tool cards and permission prompts as distinct nested objects. Border, fill and radius are spent by role, not stamped on everything.
