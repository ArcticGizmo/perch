# Recent Changes Summary

Based on the last 50 commits (`git log --oneline -50`), Perch has seen rapid, broad development across several themes.

**Overlay & widgets.** The floating overlay gained user-configurable widget reordering, horizontal resize grips, docked overlay mode, and improved placement handling (fixes for overlay jumping, toggled placement, and lower-screen positioning). A collapsible/expansion pattern was aligned across sections, and session notes were removed.

**Markdown.** A major markdown push: better rendering (code blocks, checkboxes), search and find-replace in the editor, preamble support for `.md` files, per-session indicators, text selection in preview, and editing performance improvements.

**Theming.** A full theming journey landed — multiple themes, a light-mode option, and fixes for theming not applying to certain glyphs.

**Social & productivity.** Social feed and social feedback features, user-authored to-dos, and a quiet mode to silence playful features.

**Git integration.** A GitKraken-style git tree view, better PR responsiveness on branch changes, and a right-click "open in GitKraken" option.

**Games & achievements.** Space Invaders and Frogger arcade games, plus more achievements.

**Fixes & platform.** Jira support, optional monthly-spend tracking, better Claude Desktop session detection, a Fable context-pressure fix, emoji support, dock resize fixes, and macOS tweaks.
