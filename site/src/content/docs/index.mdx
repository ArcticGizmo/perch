Running several Claude Code sessions at once means a lot of checking. Is that one finished? Is this one stuck on
a permission prompt? Perch does the checking for you. It's a **Windows and macOS** tray app that watches every
session in the background, **alerts you** when one needs you, and gets you back to it in one click.

## 1. Know when a session needs you

Every session sits in one of four states, shown in an always-on-top panel with counts in its header:

| State | What it means |
| --- | --- |
| **Running** | Working, with the current tool call and a timer under it. |
| **Idle** | Open, but not doing anything. |
| **Waiting on you** | Stopped on a permission prompt or a question. |
| **Done** | Finished, and not yet acknowledged. The panel flashes and a notification fires. |

## 3. Or run it from Perch

Perch can also start and drive Claude Code sessions itself, so you can answer without switching apps at all.

### The session window

Approve prompts, reply, @-mention files, attach images and run slash commands. Tool calls show as readable
cards, sub-agents get their own tabs, and a changed-files panel tracks what the session touched.

## How it works

Perch reads Claude Code's own files under `~/.claude/` and adds a few hooks to Claude Code's settings for you
(no plugin to install). Your session contents never leave your machine. The only network calls are update
checks and the features you turn on. See [Privacy](/perch/privacy/) for the full list.
