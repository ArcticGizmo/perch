Perch is a **Windows and macOS** tray app that watches your Claude Code sessions and shows what each one is
doing at a glance. When a session finishes, stops on a permission prompt, or otherwise needs you, you'll know.

## Four states, colour-coded

| State | Meaning |
| --- | --- |
| **Running** | Actively working, with the current tool call and a live timer. |
| **Idle** | Open, but not doing anything. |
| **Awaiting input** | Stopped on a permission prompt or a question, waiting for you. |
| **Needs attention** | Finished and waiting to be acknowledged. The panel flashes and a notification fires. |

Click a row to jump to that session's terminal.

## How it works

Perch reads Claude Code's own files under `~/.claude/` and wires a few hooks into Claude Code's settings for
you (no plugin to install). Your session contents never leave your machine. The only network calls are update
checks and the features you turn on. See [Privacy](/perch/privacy/) for the full list.
